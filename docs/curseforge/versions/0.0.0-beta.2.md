<h2>v0.0.0-beta.2 - Async log capture, no more reload freeze</h2>

<p>Bug-fix beta for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>. Fixes a client freeze / extremely slow resource-pack reload on large modpacks and removes an unused networking feature.</p>

<h3>Fixed</h3>
<ul>
<li><strong>Client freeze / very slow resource-pack reload (F3+T)</strong>: <code>CapturedAppender</code> used to <code>flush()</code> to disk under a lock on <em>every</em> <code>WARN</code>/<code>ERROR</code> record, on the logging thread. On a large modpack a reload emits thousands of warnings in parallel, so the reload worker threads (and the render thread) serialized on per-line disk I/O and the client appeared to hang. The appender now hands formatted lines to a bounded queue drained by a single daemon writer (<code>DataMiner-LogCapture</code>) with one flush per batch; the logging thread never touches disk and never blocks (lines are dropped and counted if the queue is full).</li>
<li><strong>Issue detector writes</strong>: <code>IssueRegistry</code> no longer opens/writes/closes <code>issues.jsonl</code> / <code>lootr_missing_tables.jsonl</code> per matching record on the logging thread; those writes moved onto their own daemon writer (<code>DataMiner-IssueWriter</code>). The five known-issue detectors are unchanged.</li>
<li><strong>Server tick cost while the latency tracer is running</strong>: <code>PerfEventHandlers</code> now captures the all-entities / all-chunks slow-tick snapshot at most once per second instead of on every slow tick (which, on an overloaded server, meant every tick).</li>
</ul>

<h3>Removed</h3>
<ul>
<li><strong>Client reload detection with server reporting</strong>: the client <code>PreparableReloadListener</code> that logged a stack trace and sent a <code>ClientReloadPayload</code> to the server on every resource reload, plus its payload type and server handler (<code>DataMinerClientNetworking</code>, <code>DataMinerServerNetworking</code>, <code>DataMinerNetworkPayloads</code>), have been deleted. Data Miner no longer registers any network payload.</li>
</ul>

<h3>Notes</h3>
<blockquote>Diagnostic / dev tool, no gameplay content. Verified: <code>./gradlew build</code> is green and the mod compiles clean against the 1.21.1 API. The reload-freeze fix has <strong>not</strong> yet been verified in-game against a full modpack &mdash; feedback welcome.</blockquote>
