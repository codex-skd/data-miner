<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Data Miner for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). It consolidates the <code>0.0.0-beta.1</code> &rarr; <code>0.0.0-beta.3</code> line with
no further code changes. This build has been running server-side in a full modded-server pack.</p>

<h3>What the 1.21.1 line brought</h3>
<ul>
<li><strong>API port of the 26.2 source</strong> (22 classes, no mixins, no dependencies). Full
diagnostic toolkit unchanged: registry dumps, FPS/MSPT monitor, event tracer, latency analyzer,
per-mod impact analysis, log redirect, known-issue detection and error collection &mdash; all on
background threads.</li>
<li><strong>Dedicated-server startup fix</strong>: <code>Initializer.isClientSide()</code> no longer
uses <code>Class.forName("net.minecraft.client.Minecraft")</code> (which aborted the async startup
thread on a dedicated server under NeoForge's <code>RuntimeDistCleaner</code>); it now checks
<code>FMLEnvironment.dist</code>.</li>
<li><strong>Client-freeze / slow-reload fix</strong>: <code>CapturedAppender</code> now drains a
bounded queue on a single daemon writer thread (one flush per batch) instead of locking and
<code>flush()</code>-ing on every WARN/ERROR record; <code>IssueRegistry</code> writes moved off the
logging thread; the latency tracer snapshots at most once per second. The client reload-detection
networking was removed.</li>
<li><strong>Spanish (<code>es_es</code>) locale</strong> bundled: all 6 command-feedback keys.</li>
</ul>
