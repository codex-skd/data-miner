<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Data Miner for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same diagnostic toolkit as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>API port</strong> of the 26.2 source (22 classes, no mixins, no dependencies) to the 1.21.1 API: <code>Identifier</code> &rarr; <code>ResourceLocation</code>; <code>FMLEnvironment.getDist()</code> &rarr; <code>FMLEnvironment.dist</code>; the resource-reload-listener signature; <code>WorldVersion.name()</code> &rarr; <code>getName()</code>.</li>
<li><strong>Fixed</strong>: <code>Initializer.isClientSide()</code> probed the client by <code>Class.forName("net.minecraft.client.Minecraft")</code>, which throws (not <code>ClassNotFound</code>) under NeoForge's <code>RuntimeDistCleaner</code> on a dedicated server and aborted async startup. Now uses <code>FMLEnvironment.dist.isClient()</code>.</li>
<li><strong>Feature set</strong>: registry dumps, FPS/MSPT monitor, event tracer, latency analyzer, per-mod impact analysis, log redirect, known-issue detection, error collection &mdash; all async.</li>
</ul>

<h3>Notes</h3>
<blockquote>Diagnostic / dev tool, no gameplay content. Verified: <code>./gradlew build</code> and <code>./gradlew runServer</code> load cleanly &mdash; <code>Done</code>, 0 FATAL, DataMiner generates its startup reports (<code>mods.json</code>, <code>info.json</code>, <code>mod_impact.json</code>, <code>mod_analysis.json</code>) with no errors.</blockquote>
