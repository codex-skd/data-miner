<h2>v1.2.1 - Client Reload Detection with Server Reporting</h2>

<h3>Added</h3>
<ul>
<li><strong>Client reload detection & server reporting</strong>: <code>data_miner</code> now registers a <code>PreparableReloadListener</code> on the client <code>ReloadableResourceManager</code>. When a resource reload occurs (F3+T, language change, resource pack change, or any mod-triggered reload), the client captures the stack trace and sends a <code>ClientReloadPayload</code> to the server. Server logs show: <code>[DataMiner] Client reload from <player> (UUID=...) at <timestamp></code> with full stack trace — allowing diagnosis of "random" reloads in multiplayer.</li>
</ul>

<h3>Change</h3>
<ul>
<li>Updated <code>DataMiner.java</code> to register payload handlers (<code>RegisterPayloadHandlersEvent</code>) and activate reload listener client-side via <code>FMLEnvironment.getDist().isClient()</code>.</li>
</ul>
