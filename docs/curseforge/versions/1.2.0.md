<h2>v1.2.0 - Lootr Missing Loot Table Detection</h2>

<h3>Added</h3>
<ul>
<li><strong>Lootr missing loot table detection</strong>: new issue detector captures "Error con mod [X], no con Lootr! The loot table for this container [ResourceKey[minecraft:loot_table / X:path]] does not exist" messages.</li>
<li><strong>Dedicated log file</strong>: detected issues saved to <code>startup/logs/lootr_missing_tables.jsonl</code> with <code>mod_id</code>, <code>loot_table</code>, and <code>timestamp</code> for automated datapack stub generation.</li>
<li><strong>INFO-level capture for System logger</strong>: captures Lootr chat messages (logged at INFO level) in addition to WARN/ERROR.</li>
</ul>

<h3>Change</h3>
<ul>
<li>Updated <code>IssueRegistry.java</code> with new <code>lootr_missing_loot_table</code> detector pattern.</li>
<li>Updated <code>CapturedAppender.java</code> to capture Level.INFO from "System" logger.</li>
</ul>
